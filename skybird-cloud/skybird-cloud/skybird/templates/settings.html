iPhone can't connect?
  1. Make sure the iPhone is on the same Wi-Fi as this PC (not cellular).
  2. On the PC, double-click scripts\Allow phone access.bat once and tap Yes. It lets Windows Firewall allow SkyBird on your home network.
  3. Your Wi-Fi network should be set to Private in Windows (Settings → Network & internet → Wi-Fi → your network).
Make it look like an app on your iPhone
  1. Open the address in Safari and enter your PIN.
  2. Tap the Share button, then Add to Home Screen.
  3. The SkyBird badge appears on your home screen.
Use it away from home (free, private)
  1. Install Tailscale on this PC (tailscale.com/download) and from the App Store on your iPhone. Sign in to both with the same account.
  2. Come back to this page: an Anywhere address and QR code appear. It works on cellular too, and nothing is opened to the public internet.

Video folder

Where SkyBird saves and looks for each day's 4 videos. The file names start with the flight day (yesterday), so every day sits in one folder in date order.

Today's videos go in {{ media_today }} with names like {{ media_example }}.

The four files per day end in post1_commercial.mp4, post2_private.mp4, post3_military.mp4 and post4_all.mp4, plus stats.json for the caption numbers. SkyBird makes them for you; to use your own video instead, give it the same name.

How to connect through Buffer (about 10 minutes, free)
  1. Make sure Instagram is a Professional account (Settings → Account type and tools) linked to the SkyBird Facebook Page, and TikTok is a Business or Creator account.
  2. Sign up free at buffer.com.
  3. Click Connect channels. Add Instagram, the SkyBird Facebook Page and TikTok, logging in to each. The free plan allows exactly these 3.
  4. In Buffer, open Settings → API (or your account menu → API) and create a personal API key. Copy it.
  5. Paste it in the box below and tap Connect Buffer. SkyBird finds your 3 channels automatically.
  6. When all 3 show Connected above, turn on Live mode.

Engagement numbers aren't available through Buffer's API, so check Buffer's own Analytics tab or each app's insights.

{% elif backend == 'upload_post' %}
How to connect through Upload-Post (about 10 minutes)
  1. Make sure Instagram is a Professional account (Settings → Account type and tools) and is linked to the SkyBird Facebook Page. TikTok should be a Business or Creator account.
  2. Sign up at app.upload-post.com. The free plan covers Instagram and Facebook with 10 uploads a month; TikTok and unlimited posts need the Basic plan.
  3. Create a profile named skybird. Inside it, tap Connect for Instagram, Facebook and TikTok, and log in to each. This is the normal "Log in with Facebook/TikTok" screen, not a developer account.
  4. Go to API Keys and create a key.
  5. On the PC, double-click scripts\connect_accounts.bat and paste the key. It finds your profile and Facebook Page on its own.
  6. Tap Check connections above. When all three show Connected, turn on Live mode.
{% elif backend == 'manual' %}
How manual posting works
  1. Approve in the morning as usual.
  2. At 9, 11, 1 and 6 your phone buzzes (set up notifications below). Tap it to open the post kit.
  3. Save video, then open Instagram, tap + and choose Reel, pick the video, Copy caption and paste it. Post. Do the same for Facebook and TikTok.
  4. Tap I posted it so History stays accurate.
  5. The kit only works in Live mode. In dry run nothing is readied.
{% else %}
How to connect with your own developer apps
  1. Meta: in developers.facebook.com, create a Business app, then run python -m skybird meta-setup (full steps in README section 2).
  2. TikTok: in developers.tiktok.com, create an app with the Content Posting API, then run python -m skybird tiktok-auth (README section 3).
{% endif %}
